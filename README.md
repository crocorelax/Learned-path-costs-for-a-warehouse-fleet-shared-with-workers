# Learned-path-costs-for-a-warehouse-fleet-shared-with-workers
A small neural network, trained offline by evolution, sets the path costs of a robot fleet live from robot traffic and predicted worker positions. The fast planner PIBT follows these costs, keeps throughput high, and passes close to people less often.
